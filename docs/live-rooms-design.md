# B 站直播间接入

## 界面
- 搜索结果的“歌单”后添加“直播间”，沿用当前搜索词。
- 列表显示房间名、UP 主、是否在播，提供播放操作。
- 左侧“最近播放”下面添加“直播间”，打开最近播放过的直播间列表。
- 空列表、加载中、请求失败有明确提示，失败可重试。

## 行为
- 首版播放直播声音，使用底部现有播放器控制暂停、音量。
- 播放前刷新房间状态与播放地址；未开播时提示，不切断当前音乐。
- 成功开始播放后记录房间；以房间 ID 去重，最近播放置顶，保留最多 100 条并持久化。
- 打开历史列表时刷新状态，接口失败时显示“状态未知”，不将其误判为未开播。
- 直播不使用歌曲进度拖动、断点续播和下载；直播记录不混入歌曲最近播放。

## 接入方式
- 复用 B 站源的请求方式及现有播放器，增加直播搜索与房间解析能力。
- 扩展现有本地请求转发：识别 HLS 清单，将分片和子清单地址转为携带相同请求头的转发地址。
- 转发服务仅监听本机；限制清单大小与网络等待时间，正确处理错误响应。
- 单独维护直播间模型与历史，避免扩大普通音乐搜索类型的影响范围。

## 验证
- 验证直播搜索字段、开播状态与房间解析。
- 验证 HLS 相对路径、绝对路径、子清单及 URI 属性改写，普通音频转发不回归。
- 验证历史去重、排序、持久化及失败不写入。
- 完成类型检查、构建及应用内播放验证；自动测试无法覆盖的界面和实际声音由本机检查补充。
